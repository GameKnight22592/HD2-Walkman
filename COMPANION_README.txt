Walkman audio companion v0.3.7

Requirements: 64-bit Windows, .NET Framework 4.8 and Windows Media Foundation.

1. Close Helldivers 2 and any running Walkman companion or library window.
2. Extract this entire archive. Keep the Support folder beside Install.cmd.
3. Run Install.cmd. Administrator privileges are not required.
4. Use the Walkman Music Library shortcut to add songs or choose an existing folder.
5. Import the separate Walkman_Mod.zip into HD2 Arsenal, enable it and deploy it.
6. Enable Show Walkman in the MODS settings tab.

The mod requires Bingus Shared Loader, Mod Options Menu and Mod Bindings Menu.
Run Install.cmd for initial setup and companion updates, not every session.
The mod starts the companion automatically when needed.
Imported songs and the selected music folder are preserved when updating.
The library supports MP3, WAV, FLAC and M4A; playback depends on installed codecs.
Logs: %LOCALAPPDATA%\HD2Walkman\Walkman.log
